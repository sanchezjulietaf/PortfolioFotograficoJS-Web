# 📸 Portfolio Fotográfico - Proyecto Final

Este proyecto es un sitio web desarrollado como entrega final del curso de desarrollo web. Se trata de un portfolio fotográfico responsive y optimizado, creado utilizando HTML, SASS, Flexbox, Grid y buenas prácticas de SEO. Está diseñado para presentar los trabajos, servicios y contacto de una fotógrafa profesional.

---

## 🚀 Objetivos del proyecto

- Diseñar y codificar la **estructura completa del sitio web**
- Aplicar **SASS, Flexbox y Grid** para el estilo avanzado
- Desarrollar un **diseño responsive** adaptable a distintos dispositivos
- Optimizar el sitio con técnicas de **SEO y accesibilidad**
- **Publicar el sitio online** en un servidor gratuito

## 🎨 Tecnologías utilizadas

- HTML5 semántico
- SASS (estructura modular con parciales)
- CSS3 con Flexbox y Grid
- Animaciones con `@keyframes`
- Diseño responsive con media queries (`@include respond-to`)
- Buenas prácticas de accesibilidad y SEO
